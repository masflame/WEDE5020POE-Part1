# Sunrise Bakery Website - Part 1: Building the Foundation

## Project Overview
This project is a website built for **Sunrise Bakery**, a small, family-owned
bakery based in Johannesburg, South Africa. The organisation was chosen as a
fictional (but realistic) small business for this project. The site aims to
give the bakery an online presence where customers can view products, learn
about the business, and get in touch.

## Website Goals and Objectives
- Give Sunrise Bakery a professional online presence.
- Allow visitors to learn about the bakery's history, mission, and team.
- Showcase the bakery's product range (bread, pastries, cakes).
- Provide an easy way for customers to send enquiries or place orders.
- Provide clear contact details and directions to both branches.

## Key Features and Functionality
- 5 HTML pages: Home, About Us, Products, Enquiry, Contact.
- A consistent navigation menu across all pages.
- An enquiry form for general/product questions.
- A contact form and embedded maps for two branch locations.
- A well-organised file and folder structure ready for CSS (Part 2) and
  JavaScript (Part 3).

## Part 1 Details
Part 1 focuses purely on **structure and content** - no CSS styling has been
applied yet. This is intentional, as styling is covered in Part 2. Pages use
semantic HTML5 elements (`header`, `nav`, `main`, `section`, `article`,
`footer`) and basic elements (headings, paragraphs, images, links, and forms).
